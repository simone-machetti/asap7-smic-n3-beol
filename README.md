# ASAP7 SMIC N+3 BEOL

ASAP7 for the RTL sandbox flow, with a replaceable metal stack. The cells always come from the vendored OpenROAD-flow-scripts ASAP7 tree; the seven files that describe the back end of line (BEOL) come either from that same tree, which is stock ASAP7, or from a variant folder under `beol/`. The flow selects the stack with `BEOL=<name>`, so the same design runs on both stacks from one checkout.

## Layout

```
.
├── setup.sh                        # Vendors the upstream trees and completes vendor/asap7
├── vendor/                         # Upstream copies, generated by vendor.py and never edited
│   ├── vendor.py                   # Vendoring tool
│   ├── asap7.vendor.hjson          # OpenROAD-flow-scripts, flow/platforms/asap7
│   ├── asap7sc7p5t_27.vendor.hjson # ASU cell-library repository, Verilog models only
│   ├── *.lock.hjson                # Resolved revisions (generated, not tracked)
│   ├── asap7/                      # Cells and the stock stack (generated, not tracked)
│   └── asap7sc7p5t_27/             # Source of the OA simulation model (generated, not tracked)
├── beol/
│   └── smic-n3/                    # The seven stack files of the restacked variant
├── smic_n3.md                      # Technology delta ASAP7 vs SMIC N+3 and the phased plan
└── asap2smic.md                    # File-by-file implementation of the variant
```

## What the flow reads

The flow's Makefile derives two roots from `PDK_HOME`, the path of this checkout:

| Root         | Points at                                           | Supplies                                                             |
| ------------ | --------------------------------------------------- | -------------------------------------------------------------------- |
| `ASAP7_HOME` | `vendor/asap7`, always                              | Liberty, cell LEF, GDS, simulation models, synthesis maps: the cells |
| `BEOL_HOME`  | `vendor/asap7` for `BEOL=asap7`, else `beol/<name>` | The seven metal-stack files below, read by place-and-route only      |

| File                                         | Role                                    |
| -------------------------------------------- | --------------------------------------- |
| `lef/asap7_tech_1x_201209.lef`               | Metal stack: layers, pitches, vias      |
| `openRoad/make_tracks.tcl`                   | Routing tracks per layer                |
| `openRoad/pdn/grid_strategy-M1-M2-M5-M6.tcl` | Flat power-grid strategy                |
| `setRC.tcl`                                  | Per-layer wire RC estimates             |
| `rcx_patterns.rules`                         | Parasitic extraction rules              |
| `KLayout/asap7.lyt`, `KLayout/asap7.lyp`     | Layer map and display for the GDS merge |

A variant folder holds all seven at the same relative paths as in `vendor/asap7`; nothing is taken from the stock tree for a file the variant leaves out.

Status: the files of `beol/smic-n3` are byte-identical copies of the stock ones. The two stacks therefore give identical results, which is the check that the selection mechanism works before any BEOL change is made. What each file has to become, where every number comes from and how each step is checked is written up in [asap2smic.md](asap2smic.md), and the technology difference that motivates it in [smic_n3.md](smic_n3.md).

## Use with the flow

```bash
export PDK_HOME=/path/to/asap7-smic-n3-beol # once, in ~/.bashrc

make pnr ...                                # stock ASAP7 stack (BEOL=asap7, the default)
make pnr ... BEOL=smic-n3                   # restacked variant
```

`BEOL` matters to `make pnr` only; every other target reads the cells alone. Name the output folder after the stack to tell the runs apart.

## Setting up

After a fresh clone:

```bash
bash setup.sh
```

It vendors each upstream tree that is missing under `vendor/`, then completes `vendor/asap7` in the two ways the flow needs and upstream does not provide: it unpacks the four RVT TT liberty files that upstream ships gzipped, since ABC cannot read them compressed, and it copies the OA-cell simulation model from the ASU tree, since the OpenROAD-flow-scripts package lacks it. The script can be re-run at any time; to re-vendor a tree, delete it and run again.

`vendor.py` clones the full upstream repositories (about 0.9 GB and 2.7 GB of history) into a temporary directory and rebuilds `vendor/<name>/` from scratch. If you invoke it by hand, run it from `vendor/`, since it moves the repository's `.git` aside for the duration of the run. The `rev` field of each descriptor pins the upstream revision, so every clone rebuilds the same trees.
